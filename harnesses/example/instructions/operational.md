# Starter project guidance

- Read the repository's own instructions first. Project-specific rules override this starter.
- Before changing files, inspect the relevant code and explain the smallest useful next step.
- Preserve existing work and local configuration. Never publish, push, delete or overwrite without explicit approval.
- Distinguish what you inspected, changed, tested, committed and deployed. Do not call one state another.
- When asked for a first review, stay read-only and return one concrete improvement with the file or component involved.
